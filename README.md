## Overview

RimWorld Save Our Ship 2 Ship Planner is a companion web app for the Save Our Ship 2 mod, providing a drag-and-drop ship layout designer with structural integrity visualization, total hull mass and fuel consumption estimates, weapon arc visualization, and room pressurization coverage display — helping players plan their optimal ship before building it in-game.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Save Our Ship 2 Ship Planner** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Layout Designer** | Drag-and-drop ship room and component placement on a grid |
| **Structural Integrity** | Visual overlay showing which sections maintain hull integrity |
| **Mass Calculator** | Total ship mass and fuel consumption estimates from layout |
| **Weapon Arcs** | Visualizes firing arcs for all placed ship weapons |
